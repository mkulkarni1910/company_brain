Connect SubstrateOS to Slack

One-time setup · ~5 minutes · admin access to your Slack workspace
Each reply is scoped to what the asking user can see — SubstrateOS uses their identity, not a shared bot account.
  1. 1
    Go to api.slack.com/apps → Create New App → From scratch, and name it SubstrateOS.
  2. 2
    Under OAuth & Permissions, add the bot token scopes:app_mentions:read chat:write im:read im:write
  3. 3
    Under Event Subscriptions, enable events and set the Request URL, then subscribe to app_mention and message.im.https://api.substrateos.ai/bot/slack
  4. 4
    Install to Workspace, then copy the Bot User OAuth Token and the Signing Secret.
  5. 5
    Add them to your server environment and restart the API — this card will flip to Active.SLACK_BOT_TOKEN=xoxb-… SLACK_SIGNING_SECRET=…

Connect SubstrateOS to Microsoft Teams

One-time setup · ~8 minutes · Azure Bot + Teams Admin Center access
Answers render as Adaptive Cards, and meeting context appears in the side panel during calls.
  1. 1
    In the Azure Portal, create an Azure Bot resource and set its messaging endpoint to:https://api.substrateos.ai/bot/teams
  2. 2
    Copy the App ID and App Password, add them to your server environment, and restart the API.TEAMS_BOT_APP_ID=… TEAMS_BOT_APP_PASSWORD=…
  3. 3
    Download the manifest package below, then upload it in Teams Admin Center → Apps → Manage apps → Upload an app.
  4. 4
    Done — this card will show Active on the next load.
