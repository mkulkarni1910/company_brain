★ Priority — Intelligence Design

Smart by construction

  • Hybrid retrieval (BM25 + vector) fused across Content, People & Activity pillars via RRF.
  • Personalized ranker — same query, different ranking per persona (groups + activity history).
  • Semantic Kernel orchestrator plans Live Fetch vs. cached, multi-signal ranking, grounded generation.
  • Every answer grounded with citations; out-of-corpus questions refused explicitly.
  • Conversational memory: trimmed history injected into grounded prompts — web chat, Slack threads, Teams conversations.
★ Priority — System Architecture & Engineering Quality

Production-grade, not a demo

  • Strict module boundaries — each Zone 4 component is a swappable interface.
  • Double-enforcement ACLs: index-time stamp + query-time recheck, fail-closed on outage.
  • Managed identity everywhere — no connection strings in code.
  • Eval harness from day one; pytest suite gates every change.
  • OpenTelemetry → App Insights, one trace per request with signal breakdown.

Cross-cutting

Security

Entra SSO + JWT validation; double-enforcement ACLs (index stamp + query recheck, fail-closed); managed identity; Key Vault for the rest.

Observability

structlog + OpenTelemetry → App Insights. One trace per request, ranking-signal breakdown as span attributes.

Quality gates

pytest suite + eval harness (golden Q&A recall/MRR). Frontend typecheck + lint + build.

Deploy

Docker amd64 → ACR (cbrainindiaacr) → Container Apps (rg-company-brain-india, centralindia) via the substrateos-deploy skill.

Identity flow

DefaultAzureCredential → user-assigned managed identity in cloud; OBO to Microsoft Graph for Live Fetch.

Config

pydantic-settings reads env + Key Vault; no secrets in code.
